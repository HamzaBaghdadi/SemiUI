Setup

Installation

SemiUI is copied into your project through a CLI, not installed as a compiled dependency. No Tailwind setup is assumed — bring whatever styling approach your app already uses.
Angular 22+ Standalone components & the new control-flow syntax
Any styling setup Plain CSS works out of the box. Tailwind is optional and never required
@ng-icons/core Only needed once you add a component whose preset references an icon
Step by step

From npx to a working component

1

Initialize SemiUI

Scaffolds components.json, asks which preset to start from (Semi by default, or Aurora), and installs the theme engine, primitives, and the chosen preset package. Run it from the root of an Angular project — a angular.json must already exist there.
Terminal 
npx @semiui/cli init

? Which preset would you like to start from?
  1) Semi (default)
  2) Aurora

# Created components.json
# Installing @semiui/tokens, @semiui/theme, @semiui/primitives, @semiui/presets-semi...
# Installing @semiui/cli as a dev dependency...
2

Wire up the theme provider

Every copied component reads its colors, spacing and radius from the active preset. Add the provider once and it applies to every component you add afterward.
src/app/app.config.ts 
import {{ '{' }} provideSemiUI {{ '}' }} from '@semiui/theme';
import {{ '{' }} Semi, provideSemiIcons {{ '}' }} from '@semiui/presets-semi';

export const appConfig: ApplicationConfig = {{ '{' }}
  providers: [
    // ...your existing providers
    provideSemiUI({{ '{' }} preset: Semi {{ '}' }}),
    provideSemiIcons(),
  ],
{{ '}' }};
3

Add your first component

This copies the component's real source — not a compiled bundle — into src/app/components by default. It's yours from the moment it lands: edit it, break it, delete parts you don't need.
Terminal 
npx semiui add button

# Added src/app/components/button/button.component.ts
# Added src/app/components/button/button.component.html
# Added src/app/components/button/button.component.css
#
# Done. ButtonComponent is now yours to edit.
4

Use the component

Import it with a relative path, like any other file in your project — because that's exactly what it is now.
booking-card.component.ts 
import {{ '{' }} ButtonComponent {{ '}' }} from '../components/button/button.component';

@Component({{ '{' }}
  selector: 'app-booking-card',
  imports: [ButtonComponent],
  template: `<s-button variant="primary" (pressed)="confirm()">Confirm</s-button>`,
{{ '}' }})
export class BookingCardComponent {{ '{' }}
  confirm() {{ '{' }}{{ '}' }}
{{ '}' }}
