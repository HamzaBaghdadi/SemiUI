A preset-driven component library for Angular

Own the code. Swap the theme.

SemiUI components are copied straight into your project — not installed as a black-box dependency. Every visual decision comes from a preset object you choose or write yourself, so the same button can be blue today and something else entirely tomorrow, with no rewrite.

How it works

Three commands, and it's yours

1 Initialize a preset Pick the default Semi preset or point at your own token file.
npx semi-ui init
2 Add a component Its source files land directly inside your Angular app.
npx semi-ui add button
3 Edit it like your own code Because it is — Apache-2.0, no upstream lock-in, no wrapper.
src/app/ui/button/*
Why SemiUI

Built to be changed, not just used

Presets, not hard-coding Colors, spacing, radius and per-component overrides live in one plain object. Ship the default or author your own.
Copied, not imported Every component's source lands in your repo. Read it, break it, rewrite it — it's a normal file now.
Style-system agnostic No Tailwind dependency is assumed. Set up plain CSS, Tailwind, or anything else — and bridge tokens over if you want.
Dark mode from the same preset Every preset ships a paired dark palette. One class toggle remaps the whole app.
Icons are just a mapping Each preset declares which icon renders where. Swap Lucide for your own set by editing one object.
Apache-2.0 Use it, modify it, ship it inside proprietary work — permissively licensed, on purpose.
