Presets & theming

A preset is a plain object — no build plugin, no Tailwind requirement. SemiUI reads it and injects the --semiui-* variables every copied component references.

Shape

What a preset actually is

Every preset — built-in or your own — is a plain object satisfying ThemePreset. No class, no build plugin.
theme-preset.ts 
interface ThemePreset {{ '{' }}
  name: string;
  tokens: {{ '{' }}
    color: ColorTokens;      // background, foreground, primary, border, ring...
    spacing: {{ '{' }} xs: string; sm: string; md: string; lg: string; xl: string {{ '}' }};
    radius: {{ '{' }} sm: string; md: string; lg: string; full: string {{ '}' }};
    typography: {{ '{' }} fontFamily: string; fontSizeSm: string; fontSizeMd: string; fontWeightMedium: string {{ '}' }};
    comp: ComponentTokens;   // one entry per component -- comp.button, comp.input, comp.tag...
  {{ '}' }};
  darkColor: ColorTokens;    // paired dark-mode palette
  icons: IconTokens;         // logical slot -> icon reference
{{ '}' }}

Custom presets

Writing your own

A preset is just data — spread an existing one and override only what changes. Pass the result to provideSemiUI in place of Semi or Aurora, the same call from step 2 of the installation guide.
src/app/presets/ember.preset.ts 
import {{ '{' }} Semi {{ '}' }} from '@semiui/presets-semi';
import type {{ '{' }} ThemePreset {{ '}' }} from '@semiui/tokens';

export const Ember: ThemePreset = {{ '{' }}
  ...Semi,
  name: 'ember',
  tokens: {{ '{' }}
    ...Semi.tokens,
    color: {{ '{' }}
      background: '#fffaf5',
      foreground: '#431407',
      primary: '#ea580c',
      primaryForeground: '#ffffff',
      destructive: '#dc2626',
      destructiveForeground: '#ffffff',
      border: '#fed7aa',
      ring: '#ea580c',
      muted: '#ffedd5',
      mutedForeground: '#9a3412',
    {{ '}' }},
  {{ '}' }},
  // darkColor and comp are inherited from Semi as-is -- override only what changes.
{{ '}' }};
src/app/app.config.ts 
import {{ '{' }} provideSemiUI {{ '}' }} from '@semiui/theme';
import {{ '{' }} Ember {{ '}' }} from './presets/ember.preset';

export const appConfig: ApplicationConfig = {{ '{' }}
  providers: [
    // ...your existing providers
    provideSemiUI({{ '{' }} preset: Ember {{ '}' }}),
  ],
{{ '}' }};

Icon mapping

A preset's icons object maps logical slots to a real icon. Each slot is either {{ '{' }} type: 'ng-icon', name {{ '}' }} or raw {{ '{' }} type: 'svg', markup {{ '}' }} — swap the whole set by editing this one object. @for (row of iconSlots; track row.slot) { }
Slot Default icon
{{ row.slot }} {{ row.icon }}
Inside a copied component, injectSemiUIIcons() reads the active preset's icon map:
checkbox.component.ts 
protected readonly icons = injectSemiUIIcons();

// in the template:
// <s-icon [ref]="icons.checkboxCheck" />
Dark mode

Where the dark palette comes from

Every preset pairs its light tokens.color with a darkColor object of the same shape. provideSemiUI writes both onto a single <style> tag — the base tokens on :root, the dark palette scoped under .dark — so the cascade handles switching, not JavaScript. It also installs ColorModeService, which toggles that class, persists the choice to localStorage, and falls back to the OS preference. This is exactly what the moon icon in this site's top bar calls.
topbar.component.ts 
import {{ '{' }} ColorModeService {{ '}' }} from '@semiui/theme';

@Component({{ '{' }} /* ... */ {{ '}' }})
export class TopbarComponent {{ '{' }}
  protected readonly colorModeService = inject(ColorModeService);
{{ '}' }}

// template: (click)="colorModeService.toggle()"
Optional

Bridging into Tailwind

SemiUI doesn't set up Tailwind for you, and its injected --semiui-* variables live independently of any @theme block. If your project already uses Tailwind, map the two together by hand — only where you actually want a Tailwind utility backed by the active preset.
src/styles.css 
@import "tailwindcss";
@import "./my-app.css"; /* wherever provideSemiUI's injected <style> lands is untouched by this */

@theme {{ '{' }}
  --color-primary: var(--semiui-color-primary);
  --color-background: var(--semiui-color-background);
  /* map the rest of --semiui-* the same way, only where you need Tailwind utilities */
{{ '}' }}
