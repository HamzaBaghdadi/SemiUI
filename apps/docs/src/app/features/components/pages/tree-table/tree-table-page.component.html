Basic usage

Selection

selectionMode="multiple" adds a checkbox column. Selecting a parent doesn't cascade to its children -- selection tracks exactly the nodes picked.

Selected: {{ selection().length }} node(s)

Custom cell rendering

The #cell template slot renders every cell -- context is {{ '{' }} $implicit: value, node, column, level {{ '}' }}, so it typically switches on column.field.

@if (column.field === 'name') { {{ value }} } @else { {{ value }} }
