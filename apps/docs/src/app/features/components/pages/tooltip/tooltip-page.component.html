Positioned with the same position: fixed + viewport-flip technique as Popover.

Basic usage

Placement

tooltipPlacement accepts top (default) / bottom / left / right, and flips top/bottom automatically when there isn't room.

left/right pin to that literal physical side regardless of page direction. start/end are the mirroring equivalents, flipping side under dir="rtl".

Delay

tooltipDelay is the time in milliseconds before it appears (default 300).

Works on any element
