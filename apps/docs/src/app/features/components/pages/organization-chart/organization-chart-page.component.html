Basic usage

Selection

selectionMode="single" makes every node clickable (and focusable via keyboard, Enter/Space toggles it).

Selected: {{ selection().length ? selection()[0].data.label : 'none' }}

Without collapsing

[collapsible]="false" drops the toggle from every node -- the whole tree always renders fully expanded.

Custom node content

The #node template slot renders every node's content -- context is {{ '{' }} $implicit: data, node, expanded, selected {{ '}' }}.

{{ person.label }} @if (person.title) { {{ person.title }} }
