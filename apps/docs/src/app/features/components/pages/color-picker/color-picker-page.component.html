Append to body

By default the panel is positioned relative to its own trigger, which gets cut off when an ancestor clips overflow — a Dialog, a Drawer, or any scrollable card. Set appendTo="body" to move it to document.body instead — it stays pixel-positioned against its anchor, but escapes the clipping container.
