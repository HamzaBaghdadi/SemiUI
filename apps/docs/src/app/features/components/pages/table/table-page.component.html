Basic usage with sorting

There's no table-wide "enable sorting" switch -- each column decides for itself via sortable. Click a sortable header to cycle asc / desc / unsorted. The "Age" column also sets align.

A column's align accepts 'left'/'right', which pin to that literal physical side regardless of page direction, or 'start'/'end' (used below), the mirroring equivalents that flip side under dir="rtl". Both pass straight through to CSS text-align.

Striped rows and gridlines

Reference

  • columns / data -- column defs and row objects.
  • rowKey -- identity function for selection tracking; defaults to the row object itself.
  • selectionMode -- "none" (default) / "single" / "multiple", with a two-way bindable selection.
  • filterable -- global search across every column's field value.
  • paginated / pageSize / rowsPerPageOptions.
  • Templates: #cell, #header, #footer, #loading.
  • rowClick output -- emits the clicked row, regardless of selectionMode.
