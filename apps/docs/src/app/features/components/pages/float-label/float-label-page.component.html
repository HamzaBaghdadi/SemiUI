Pure CSS, no JS state tracking. Give the wrapped field placeholder=" " (a single space) if it has no natural placeholder of its own -- native-input fields need a placeholder attribute present for the filled-state detection to work at all.

Over (default)

Clears the border entirely once floated -- classic Material.

On

Floats to sit right on the border line.

In (Ifta Label)

Stays inside the field's own box the whole time, just rising and shrinking -- PrimeNG's IftaLabel.

Any field

Works with button-triggered fields like Select too (detected via the absence of its own placeholder element, not :placeholder-shown), and multi-line fields like Textarea.
