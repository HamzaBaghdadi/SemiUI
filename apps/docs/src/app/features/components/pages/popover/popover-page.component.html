Placement

placement accepts top / bottom (default) / left / right, and flips top/bottom automatically when there isn't room.

left/right pin to that literal physical side regardless of page direction. start/end are the mirroring equivalents, flipping side under dir="rtl".
Top I'm above the button. Left I'm to the left. Start I'm on the reading-start side. End I'm on the reading-end side.

Alignment

align controls where the panel lands along the cross-axis relative to the anchor -- independent of placement, which side it's on. 'center' (default) centers it; 'start'/'end' flush an edge instead, following reading direction for top/bottom placements the same way placement's start/end does. The arrow tracks the anchor's actual position either way.

align="start" Flush with the button's start edge. align="center" Centered (default). align="end" Flush with the button's end edge.

Append to body

Without appendTo, a popover trapped inside an overflow: hidden container can get clipped even though it's position: fixed. Setting appendTo="body" escapes it.

Clipped (no appendTo) You probably can't see me. appendTo body I escape the clipping container.
