Scatter

Points only, no connecting line -- otherwise the same axis/gridline/tooltip system as line and bar.

Radar

One spoke per label, arranged evenly around a circle -- each series renders as a closed polygon.

Stacked bar

stacked piles each label's series on top of each other instead of side-by-side.

Stacked area

Each series layers on top of the running sum of the ones before it, instead of every series sharing the same zero baseline.

Negative values

The value domain extends below zero automatically -- the baseline moves up to sit at zero instead of always pinning to the bottom edge, so negative bars/points render downward from it rather than clipping off the chart.

Every cartesian and radar chart mirrors automatically under dir="rtl" (toggle it from the topbar's "Customize theme" popover) -- the whole plot flips via a single CSS transform on the SVG, with axis labels counter-mirrored so they stay readable. Pie/donut are unaffected, since a circle has no inherent direction.

No grid, no legend

Options

  • type -- "line" (default) / "bar" / "area" / "pie" / "donut".
  • series -- array of { name, values, color? }. Pie/donut use only series[0].
  • valueFormatter -- formats axis labels and tooltip values.
  • colors -- palette array, cycles by index when a series/slice has no explicit color.
