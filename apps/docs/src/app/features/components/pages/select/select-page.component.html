Custom templates

Five named <ng-template> slots: #selected (the closed trigger's content), #option (each row in the list), #icon (replaces the default chevron), and #header / #footer.

Angular's strict template checker can't infer a concrete type for let-option on a content-projected template (that needs a structural directive with ngTemplateContextGuard). Wrap property access in $any(option) inside these templates -- it's a compile-time-only cast, the runtime value is still your real option.
@if (option) { {{ $any(option).code }} — {{ $any(option).name }} } {{ selected ? '✓' : '' }} {{ $any(option).name }} ({{ $any(option).code }}) Available Countries

Append to body

By default the panel is positioned relative to its own trigger, which breaks if an ancestor clips overflow. Set appendTo="body" to move the panel to document.body instead -- it stays pixel-positioned against the trigger, but escapes the clipping container.

Keyboard

Enter / Space / ↓ / ↑ open the panel; Backspace/Delete on the closed trigger clears the value. Once open, ↑/↓/Home/End move the highlighted option, Enter selects it, and Escape or clicking outside closes the panel.
