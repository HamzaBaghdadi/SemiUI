Avatar

Shows an image, falling back to initials derived from name, falling back to a generic person icon if neither is available. Falls back automatically on image load failure too.

Installation

npx semiui add avatar

Image, initials, and icon fallback

<z-avatar src="https://example.com/photo.jpg" name="Ada Lovelace" />  <!-- image -->
<z-avatar name="Grace Hopper" />  <!-- initials: GH -->
<z-avatar />  <!-- generic icon -->

Sizes

<z-avatar size="sm" />  <!-- also "md" (default), "lg", "xl" -->

Shape

<z-avatar shape="square" />  <!-- default is "circle" -->

Status

<z-avatar status="online" />  <!-- also "away", "busy", "offline" -->
