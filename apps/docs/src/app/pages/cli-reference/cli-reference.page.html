CLI Reference

The zaytoon package is a single binary with two commands.

zaytoon init

npx zaytoon init

Run this once, from the root of an Angular project (wherever angular.json is).

  • Refuses to run if no angular.json is found in the current directory.
  • Writes components.json with defaults (preset: "aurora", componentsDir: "src/app/components", prefix: "z") -- and does nothing if one already exists, so it's safe to run again.
  • Detects your package manager from the lockfile present (pnpm-lock.yaml → pnpm, yarn.lock → yarn, otherwise npm) and installs @zaytoon/tokens, @zaytoon/theme, @zaytoon/primitives, and @zaytoon/presets-aurora.
  • Prints the provideZaytoonUI wiring for app.config.ts.

zaytoon add <component>

npx zaytoon add button

Run this once per component you want in your project.

  • Copies the component's files into <componentsDir>/<component>/ (from components.json, or the default if you haven't run init).
  • Never overwrites a file that already exists. If you've edited a copied component and run add again, your changes are left alone -- you'll see "already exists ... not overwriting" instead.
  • Installs whatever npm packages that component needs, if they aren't already present.
  • Also adds any other recipe it depends on (e.g. text-input and password both pull in error-message automatically) -- same never-overwrite guarantee applies to those too.
  • If a component references icons that aren't part of your preset's default set, prints the provideIcons({ ... }) registration you need to add. Password and Select's icons are theme defaults already registered by provideAuroraIcons(), so this won't come up for them unless you override with a custom icon.
  • Run with no component name to see the full list of what's available.

Available components

Name Adds
error-message Error Message -- animated error text, standalone or used by the form components below.
button Button -- variants, sizes, loading state, icons.
text-input Text Input -- ngModel, reactive forms, and Signal Forms.
password Password -- same form support, plus a show/hide toggle.
select Select -- listbox select with custom template slots.
switch Switch -- toggle switch with sizes and optional on/off icons.
checkbox Checkbox -- checkbox with sizes and an indeterminate state.
radio-group Radio Group -- radio group with the same options shape as Select.
textarea Textarea -- multi-line text input with auto-resize and a character counter.
input-number Input Number -- numeric input with stepper buttons, min/max, and prefix/suffix.
otp OTP -- one-time-password input with auto-advance and paste support.
multiselect Multiselect -- multi-select listbox with chips, search, and select all/clear all.
popover Popover -- reference-controlled popover, positioned against whatever triggered it.
tooltip Tooltip -- [zTooltip] directive, works on any element.
divider Divider -- horizontal or vertical rule, with an optional centered label.
skeleton Skeleton -- shimmering loading placeholder, rect/circle/text shapes.
avatar Avatar -- image avatar with initials/icon fallback and a status dot.
tag Tag -- small label/chip with color variants and a removable state.
breadcrumb Breadcrumb -- a trail of ancestor pages, using RouterLink.
pagination Pagination -- page-number buttons that collapse to an ellipsis for large page counts.
rating Rating -- star rating with ngModel/reactive/Signal Forms support.
badge Badge -- notification count/dot indicator, overlay or standalone.
accordion Accordion -- data-driven collapsible panels, single- or multiple-open, pure-CSS animation.
tabs Tabs -- data-driven tab strip, horizontal/vertical, measured sliding indicator, keyboard navigation.
stepper Stepper -- step progress indicator, linear mode, horizontal/vertical orientation.
slider Slider -- drag/click/keyboard range slider, ticks, value bubble, ngModel/reactive forms.
dialog Dialog -- modal dialog, focus trap, scroll lock, focus restoration.

Works offline

Component source ships bundled inside the zaytoon npm package itself -- there's no registry server involved, so add works without network access beyond the initial npm install.
