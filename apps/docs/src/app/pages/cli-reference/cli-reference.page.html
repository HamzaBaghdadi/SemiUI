CLI Reference

The zaytoon package is a single binary with two commands.

zaytoon init

npx zaytoon init

Run this once, from the root of an Angular project (wherever angular.json is).

  • Refuses to run if no angular.json is found in the current directory.
  • Writes components.json with defaults (preset: "aurora", componentsDir: "src/app/components", prefix: "z") -- and does nothing if one already exists, so it's safe to run again.
  • Detects your package manager from the lockfile present (pnpm-lock.yaml → pnpm, yarn.lock → yarn, otherwise npm) and installs @zaytoon/tokens, @zaytoon/theme, @zaytoon/primitives, and @zaytoon/presets-aurora.
  • Prints the provideZaytoonUI wiring for app.config.ts.

zaytoon add <component>

npx zaytoon add button

Run this once per component you want in your project.

  • Copies the component's files into <componentsDir>/<component>/ (from components.json, or the default if you haven't run init).
  • Never overwrites a file that already exists. If you've edited a copied component and run add again, your changes are left alone -- you'll see "already exists ... not overwriting" instead.
  • Installs whatever npm packages that component needs, if they aren't already present.
  • For components that use specific icons (like Password's show/hide toggle), prints the provideIcons({ ... }) registration you need to add.
  • Run with no component name to see the full list of what's available.

Available components

Name Adds
button Button -- variants, sizes, loading state, icons.
text-input Text Input -- ngModel, reactive forms, and Signal Forms.
password Password -- same form support, plus a show/hide toggle.

Works offline

Component source ships bundled inside the zaytoon npm package itself -- there's no registry server involved, so add works without network access beyond the initial npm install.
