Carousel

A single-slide-at-a-time carousel: pass items and render each slide through the required #slide template slot, same convention as Tabs'/Accordion's content slot. Arrow keys (when focused), drag/swipe, arrow buttons, and dot indicators all move the same activeIndex.

Installation

npx zaytoon add carousel

Basic usage

{{ item.label }} 
protected slides = [
  { color: '#ef4444', label: 'Slide 1' },
  { color: '#f59e0b', label: 'Slide 2' },
};

<z-carousel [items]="slides">
  <ng-template #slide let-item>
    <div [style.background]="item.color">{{ '{{ item.label }}' }}</div>
  </ng-template>
</z-carousel>

Autoplay

{{ item.label }} 
<z-carousel [items]="slides" [autoplay]="true" [autoplayInterval]="2000">...</z-carousel>
<!-- pauses automatically while hovered -->

No loop, no dots

{{ item.label }}

The arrows disable at the first/last slide instead of wrapping around.

<z-carousel [items]="slides" [loop]="false" [showDots]="false">...</z-carousel>

Options

  • items -- any array; the #slide template controls how each renders.
  • activeIndex -- two-way bindable, default 0.
  • loop -- default true.
  • autoplay -- default false; autoplayInterval in ms, default 4000.
  • showArrows / showDots -- default true.

Keyboard and touch

Focus the carousel and use ←/→. On touch devices (or with a mouse), drag the slide to swipe between slides -- releasing past a threshold advances/retreats.
