Button

A behavior-driven button: variants, sizes, a loading state, and leading/trailing icons.

Installation

npx zaytoon add button

This copies button.component.ts, .html, and .css into your project. You own the code from that point on — edit it freely.

Variants

@for (variant of variants; track variant) { {{ variant }} } 
<z-button variant="primary">primary</z-button>
<z-button variant="destructive">destructive</z-button>

Sizes

@for (size of sizes; track size) { Size {{ size }} } 
<z-button size="sm">Small</z-button>
<z-button size="icon" [iconLeading]="saveIcon" aria-label="Save" />

Icons

Pass an IconRef — either an ng-icon name ({ type: 'ng-icon', name: 'lucideSave' }) or raw SVG markup ({ type: 'svg', markup: '<svg>...</svg>' }) — to iconLeading or iconTrailing.

Save 
<z-button [iconLeading]="{ type: 'ng-icon', name: 'lucideSave' }">Save</z-button>

Loading state

loading disables the button and swaps in the active theme's default loading icon (Aurora.icons.loading). Override it per preset, or override the icon per instance the same way as any other icon input.

Submit 
<z-button [loading]="isSubmitting()">Submit</z-button>
