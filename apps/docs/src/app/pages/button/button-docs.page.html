Button

A behavior-driven button: variants, sizes, a loading state, and leading/trailing icons.

Installation

npx zaytoon add button

This copies button.component.ts, .html, and .css into your project. You own the code from that point on — edit it freely.

Variants

@for (variant of variants; track variant) { {{ variant }} } 
<z-button variant="primary">primary</z-button>
<z-button variant="destructive">destructive</z-button>

Severity

A shared semantic color vocabulary across Button, Tag, and Badge. danger is a plain alias of destructive above -- both work.

@for (severity of severities; track severity) { {{ severity }} } 
<z-button variant="success">success</z-button>
<z-button variant="info">info</z-button>
<z-button variant="warn">warn</z-button>
<z-button variant="help">help</z-button>
<z-button variant="danger">danger</z-button>
<z-button variant="contrast">contrast</z-button>

Outlined and text

outlined and text (the old dedicated "outline"/"ghost" variants) are now modifiers that combine with any variant -- transparent background either way, outlined keeps a border in the variant's color, text has none.

@for (severity of allSeverities; track severity) { {{ severity }} }
@for (severity of allSeverities; track severity) { {{ severity }} } 
<z-button variant="success" [outlined]="true">success</z-button>
<z-button variant="danger" [text]="true">danger</z-button>

Sizes

@for (size of sizes; track size) { Size {{ size }} } 
<z-button size="sm">Small</z-button>

Icon-only

icon hides the label and shows just iconLeading, sized to a perfect square at whatever size is set. Always pair it with aria-label since there's no visible text. 

<z-button icon [iconLeading]="{ type: 'ng-icon', name: 'lucideSave' }" aria-label="Save" />

Icons

Pass an IconRef — either an ng-icon name ({ type: 'ng-icon', name: 'lucideSave' }) or raw SVG markup ({ type: 'svg', markup: '<svg>...</svg>' }) — to iconLeading or iconTrailing.

Save 
<z-button [iconLeading]="{ type: 'ng-icon', name: 'lucideSave' }">Save</z-button>

Loading state

loading disables the button and swaps in the active theme's default loading icon (Aurora.icons.loading). Override it per preset, or override the icon per instance the same way as any other icon input.

Submit 
<z-button [loading]="isSubmitting()">Submit</z-button>
