Color Mode

Light/dark mode is installed automatically by provideSemiUI() -- there's nothing extra to set up. ColorModeService is what runs it: a small, providedIn: 'root' service that persists the choice, falls back to the OS preference when nothing's stored, and toggles a class on <html>.

The toggle in this site's header uses exactly the API below. Try it now, then come back -- the button on this page and the one in the header are the same singleton, so they stay in sync.

Live demo

API

Member What it does
dark: Signal<boolean> The current mode. Read it anywhere -- it updates reactively.
mode: Signal<'light' | 'dark'> Same thing, as a string, if that reads better in your template.
toggle() Flips the current mode.
setDark(dark: boolean) Sets the mode directly -- useful for a light/dark/system three-way switch. 
import { Component, inject } from '@angular/core';
import { ColorModeService } from '@semiui/theme';

@Component({
  selector: 'app-header',
  template: `
    <button (click)="colorMode.toggle()">
      {{ colorMode.dark() ? 'Light mode' : 'Dark mode' }}
    </button>
  `,
})
export class Header {
  protected readonly colorMode = inject(ColorModeService);
}

What happens on toggle

Every time dark changes, an internal effect:

  1. Toggles the dark-mode class on document.documentElement.
  2. Sets document.documentElement.style.colorScheme, so native form controls and scrollbars match too.
  3. Persists the choice to localStorage.

On startup, the initial value comes from localStorage if present, otherwise from prefers-color-scheme. Both localStorage and matchMedia access are guarded -- missing either (SSR, a locked-down environment, a test runner) just falls back to light mode rather than throwing.

Configuring the storage key and class name

By default the class is dark and the storage key is semiui-color-mode. Override either through provideSemiUI: 

provideSemiUI({
  preset: Aurora,
  colorMode: {
    storageKey: 'my-app-theme',
    darkClassName: 'dark-mode', // e.g. to match an existing convention in your CSS
  },
})

Whatever you choose, it's the same class your custom preset's dark palette gets scoped under -- see Theming.
