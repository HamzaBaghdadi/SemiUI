Textarea

A multi-line text input with the same form support as Text Input, plus optional auto-resize and a character counter.

Installation

npx semiui add textarea

ngModel

Model value: {{ bio }}

<s-textarea [(ngModel)]="bio" placeholder="Tell us about yourself" />

Reactive forms + validation + maxLength

maxLength shows a character counter and caps native input at that length.

protected reactiveForm = new FormGroup({
  feedback: new FormControl('', { nonNullable: true, validators: [Validators.required, Validators.maxLength(280)] }),
});

<div [formGroup]="reactiveForm">
  <s-textarea formControlName="feedback" [maxLength]="280" errorMessage="Feedback is required (max 280 characters)." />
</div>

Signal Forms

Model value: {{ profileModel().notes }}

protected profileModel = signal({ notes: '' });
protected profileForm = form(this.profileModel);

<s-textarea [formField]="profileForm.notes" />

Auto-resize

Grows to fit its content instead of scrolling internally -- keeps working even when the value is set programmatically, not just while typing.

<s-textarea [autoResize]="true" [rows]="2" />
