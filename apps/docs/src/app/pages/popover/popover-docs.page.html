Popover

Controlled by reference from anywhere in the template -- not just its own immediate DOM neighborhood. Any element's own click handler calls po.toggle($event), show($event), or hide(); the popover reads the event's target to know what to anchor itself to and position against, using position: fixed so it renders correctly regardless of DOM nesting.

Installation

npx zaytoon add popover

Basic usage

Click to show popover Popover opened! 
<z-button (click)="po.toggle($event)">Click to show popover</z-button>

<z-popover #po>
  <span>Popover opened!</span>
</z-popover>

show() / hide() from separate triggers

Show Hide Rich content works too

Any projected content is fine -- text, forms, other components.

 
<z-button (click)="po.show($event)">Show</z-button>
<z-button (click)="po.hide()">Hide</z-button>
<z-popover #po placement="right">...</z-popover>

Placement

placement accepts top / bottom (default) / left / right, and flips top/bottom automatically when there isn't room.

Top I'm above the button. Left I'm to the left.

Options

  • offset -- gap in pixels between the anchor and the panel (default 8).
  • closeOnOutsideClick / closeOnEscape -- default true.
  • closeOnScroll -- default true; hides the popover on scroll instead of repositioning it to chase the anchor. Set false to keep it following instead.
  • showArrow -- default true; disable if the panel might get clamped near a viewport edge, where the arrow would no longer line up with the anchor.
  • appendTo -- set to "body" to move the panel to a direct child of document.body, escaping an ancestor's overflow: hidden clipping or a stacking context created by transform/filter. It's already position: fixed, so this doesn't change how it's positioned -- only where it lives in the DOM.
No arrow, no outside-click close Only Escape or the trigger itself closes me.

Append to body

Without appendTo, a popover trapped inside an overflow: hidden container gets clipped even though it's position: fixed -- an ancestor with a transform/filter creates a new containing block for fixed-position descendants. Setting appendTo="body" escapes it.

Clipped (no appendTo) You probably can't see me. appendTo body I escape the clipping container. 
<z-popover #po appendTo="body">...</z-popover>
