Quick Start

From a fresh Angular 22 app to a working, themed button.

1. Initialize

From your project root (wherever angular.json lives):

npx semiui init

This does three things:

  1. Writes components.json at the project root -- the CLI's config for where components land and which preset you're using.
  2. Installs @semiui/tokens, @semiui/theme, @semiui/primitives, and @semiui/presets-aurora.
  3. Prints the provider wiring you need to add yourself (see next step).
{
  "preset": "aurora",
  "componentsDir": "src/app/components",
  "prefix": "z"
}

componentsDir is where semiui add puts new components. Change it before adding anything if you'd rather they land somewhere else.

2. Wire up the provider

Add these two calls to app.config.ts:

import { provideSemiUI } from '@semiui/theme';
import { Aurora, provideAuroraIcons } from '@semiui/presets-aurora';

export const appConfig: ApplicationConfig = {
  providers: [
    // ...your existing providers
    provideSemiUI({ preset: Aurora }),
    provideAuroraIcons(),
  ],
};

This isn't automated on purpose -- editing app.config.ts for you would mean parsing and rewriting your source, which is exactly the kind of fragile magic this library tries to avoid. Two lines, copy-pasted once, is the whole cost.

3. Add a component

npx semiui add button

This copies button.component.ts, .html, and .css into src/app/components/button/ and installs anything it needs that you don't already have. Running add button again won't overwrite files you've already edited. 

import { ButtonComponent } from './components/button/button.component';

@Component({
  imports: [ButtonComponent],
  template: `<s-button variant="primary">Click me</s-button>`,
})
export class MyPage {}
