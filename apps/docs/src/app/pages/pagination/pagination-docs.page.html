Pagination

Page-number buttons with prev/next (and optional first/last), collapsing to an ellipsis for large page counts.

Installation

npx semiui add pagination

Basic usage

Current page: {{ page() }}

<z-pagination [(page)]="page" [pageCount]="5" />

Large page counts (ellipsis)

Collapses to an ellipsis once the page count exceeds what fits -- siblingCount controls how many page numbers show on each side of the current page.

Current page: {{ bigPage() }}

<z-pagination [(page)]="page" [pageCount]="50" [siblingCount]="1" />

No first/last buttons

<z-pagination [showFirstLast]="false" />
