Dialog

A modal dialog, controlled by reference like Popover: call dlg.show() / dlg.hide() / dlg.toggle() from anywhere. Always portals to document.body -- a modal nested in page flow defeats the point -- traps Tab/Shift+Tab focus within itself while open, locks background scroll, and restores focus to whatever triggered it on close.

Installation

npx zaytoon add dialog

Basic usage

Open dialog

Are you sure you want to continue? This can't be undone.

Cancel Confirm 
<z-button (click)="dlg.show()">Open dialog</z-button>

<z-dialog #dlg title="Confirm action">
  <p>Are you sure you want to continue?</p>
  <ng-template #footer>
    <z-button variant="outline" (click)="dlg.hide()">Cancel</z-button>
    <z-button (click)="dlg.hide()">Confirm</z-button>
  </ng-template>
</z-dialog>

Custom header template

Open ⚠ Custom header content

The header slot replaces the plain title text -- the close button still renders alongside it.

 
<z-dialog #dlg>
  <ng-template #header><strong>Custom header</strong></ng-template>
  <p>Body content</p>
</z-dialog>

Options

  • title -- plain-text header, ignored if a #header template is provided.
  • size -- "sm" / "md" (default) / "lg" / "full".
  • closable -- default true; shows the "x" close button.
  • closeOnOutsideClick / closeOnEscape -- default true.

Methods

  • show() -- opens the dialog, remembers the currently-focused element to restore later.
  • hide() -- closes the dialog and returns focus to whatever triggered it.
  • toggle()
