Dialog

A modal dialog, controlled by reference like Popover: call dlg.show() / dlg.hide() / dlg.toggle() from anywhere. Always portals to document.body -- a modal nested in page flow defeats the point -- traps Tab/Shift+Tab focus within itself while open, locks background scroll, and restores focus to whatever triggered it on close.

Installation

npx semiui add dialog

Headless template

#headless replaces the entire header/body/footer chrome with raw projected content -- the dialog still portals, traps focus, and animates, but none of the default layout, padding, title, or close button is rendered.

Open

  <ng-template #headless>
    <div class="my-custom-dialog">...</div>
  </ng-template>
</z-dialog>

Blur backdrop & hidden backdrop

blurBackdrop adds a backdrop-filter: blur() behind the dialog in addition to dimming it. showBackdrop (default true) can be set to false to remove the dimming/blur entirely -- the dialog still portals, traps focus, and locks scroll, it just doesn't visually cover the page behind it.

Blurred backdrop No backdrop

The page behind this dialog is dimmed and blurred.

No dimming layer behind this dialog -- everything else stays interactive-looking, though the dialog still traps focus.

 
<z-dialog #dlg [blurBackdrop]="true">...</z-dialog>
<z-dialog #dlg [showBackdrop]="false">...</z-dialog>

DialogService -- open any component imperatively

For dialogs that don't have a fixed place in a template (confirmations opened from a list, forms opened from a table row), inject DialogService and call open(Component, config) -- PrimeNG's DynamicDialog, essentially. The opened component gets the full Dialog chrome (backdrop, focus trap, scroll lock, animations) automatically. Inside it, inject DialogRef to close itself (optionally with a result) and DIALOG_DATA to read whatever was passed as config.data.

Open via DialogService @if (serviceResult(); as result) { {{ result }} } 
@Component({
  selector: 'app-confirm-delete-dialog',
  template: `
    <p>Delete "{{ '{{' }} data.itemName {{ '}}' }}"?</p>
    <z-button (click)="dialogRef.close(false)">Cancel</z-button>
    <z-button variant="danger" (click)="dialogRef.close(true)">Delete</z-button>
  `,
})
class ConfirmDeleteDialogContent {
  data = inject<{ itemName: string }>(DIALOG_DATA);
  dialogRef = inject<DialogRef<boolean>>(DialogRef);
}

// elsewhere:
const ref = this.dialogService.open(ConfirmDeleteDialogContent, {
  title: 'Confirm deletion',
  data: { itemName: 'Q3 Report.pdf' },
});
ref.result.then((confirmed) => { ... });

Options

  • title -- plain-text header, ignored if a #header or #headless template is provided.
  • size -- "sm" / "md" (default) / "lg" / "full".
  • closable -- default true; shows the "x" close button.
  • closeOnOutsideClick / closeOnEscape -- default true.
  • blurBackdrop -- default false; blurs whatever is behind the backdrop, in addition to dimming it.
  • showBackdrop -- default true; set to false to remove the dimming/blur layer entirely.

Methods

  • show() -- opens the dialog, remembers the currently-focused element to restore later.
  • hide() -- closes the dialog and returns focus to whatever triggered it.
  • toggle()
