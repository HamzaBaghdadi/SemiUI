Switch

A toggle switch supporting ngModel, reactive forms, and Signal Forms. The thumb's travel distance is computed in CSS from the track and thumb size tokens, so it's never off-center.

Installation

npx zaytoon add switch

ngModel

Model value: {{ notifications }}

<z-switch [(ngModel)]="notifications" label="Email notifications" />

Reactive forms + validation

Uncheck it to see the errorMessage -- same input as Text Input. 

protected reactiveForm = new FormGroup({
  terms: new FormControl(false, { nonNullable: true, validators: Validators.requiredTrue }),
});

<div [formGroup]="reactiveForm">
  <z-switch formControlName="terms" label="I agree to the terms" errorMessage="You must agree to continue." />
</div>

Signal Forms

Model value: {{ profileModel().marketing }}

protected profileModel = signal({ marketing: false });
protected profileForm = form(this.profileModel);

<z-switch [formField]="profileForm.marketing" label="Marketing emails" />

Sizes

<z-switch size="sm" />  <!-- also "md" (default) and "lg" -->

Icons

onIcon / offIcon render inside the thumb -- both optional, omit either (or both) for a plain thumb.

<z-switch [onIcon]="{ type: 'ng-icon', name: 'lucideCheck' }" [offIcon]="{ type: 'ng-icon', name: 'lucideX' }" />
