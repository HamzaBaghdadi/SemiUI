Tooltip

A [zTooltip] directive that shows a small floating label on hover/focus of any element -- no extra markup needed. The panel is a dynamically created component (via ViewContainerRef.createComponent), positioned with the same position: fixed + viewport-flip technique as Popover.

Installation

npx semiui add tooltip

Basic usage

<button [zTooltip]="'Saves your changes'">Hover or focus me</button>

Placement

tooltipPlacement accepts top (default) / bottom / left / right, and flips top/bottom automatically when there isn't room.

Delay

tooltipDelay is the time in milliseconds before it appears (default 300).

<button [zTooltip]="'Appears instantly'" [tooltipDelay]="0">No delay</button>
