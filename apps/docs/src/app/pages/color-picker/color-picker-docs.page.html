Color Picker

A hex color picker: a saturation/value square, a hue slider, a typeable hex field, and preset swatches. Trigger + popover panel by default, or set inline to render the panel directly with no trigger. Supports ngModel, reactive forms, and Signal Forms -- the bound value is a #rrggbb hex string (no alpha channel).

Installation

npx zaytoon add color-picker

Basic usage (ngModel)

Model value: {{ brandColor }}

<z-color-picker [(ngModel)]="brandColor" />

Inline

<z-color-picker [(ngModel)]="color" [inline]="true" />

Custom presets

protected presets = ['#ef4444', '#22c55e', '#3b82f6', '#f59e0b', '#a855f7'];

<z-color-picker [(ngModel)]="color" [presets]="presets" />

Reactive forms

protected reactiveForm = new FormGroup({
  accent: new FormControl<string | null>(null, Validators.required),
});

<div [formGroup]="reactiveForm">
  <z-color-picker formControlName="accent" errorMessage="Please pick an accent color." />
</div>

Signal Forms

Model value: {{ profileModel().themeColor }}

protected profileModel = signal({ themeColor: '#ec4899' });
protected profileForm = form(this.profileModel);

<z-color-picker [formField]="profileForm.themeColor" />

Disabled

Options

  • inline -- default false.
  • presets -- array of hex strings, defaults to a 19-color palette.
  • placeholder -- shown in the trigger when no value is set.
