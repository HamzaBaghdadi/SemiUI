Color Picker

A hex color picker: a saturation/value square, a hue slider, a typeable hex field, and preset swatches. Trigger + popover panel by default, or set inline to render the panel directly with no trigger. Supports ngModel, reactive forms, and Signal Forms -- the bound value is a #rrggbb hex string (no alpha channel).

Installation

npx semiui add color-picker

Basic usage (ngModel)

Model value: {{ brandColor }}

<s-color-picker [(ngModel)]="brandColor" />

Inline

<s-color-picker [(ngModel)]="color" [inline]="true" />

Custom presets

protected presets = ['#ef4444', '#22c55e', '#3b82f6', '#f59e0b', '#a855f7'];

<s-color-picker [(ngModel)]="color" [presets]="presets" />

Reactive forms

protected reactiveForm = new FormGroup({
  accent: new FormControl<string | null>(null, Validators.required),
});

<div [formGroup]="reactiveForm">
  <s-color-picker formControlName="accent" errorMessage="Please pick an accent color." />
</div>

Signal Forms

Model value: {{ profileModel().themeColor }}

protected profileModel = signal({ themeColor: '#ec4899' });
protected profileForm = form(this.profileModel);

<s-color-picker [formField]="profileForm.themeColor" />

Disabled

Swatch-only trigger

Hide the presets section and the hex text next to the swatch, e.g. for a compact swatch-only trigger.

<s-color-picker [(ngModel)]="color" [showPresets]="false" [showValueText]="false" />

Options

  • inline -- default false.
  • presets -- array of hex strings, defaults to a 19-color palette.
  • showPresets -- default true; hides the presets section (an empty presets array does this too).
  • showValueText -- default true; hides the hex text next to the swatch in the trigger.
  • placeholder -- shown in the trigger when no value is set (and showValueText is on).
