Zaytoon

An Angular UI library built on two ideas: provider-based theming -- one call wires up a full design-token system with light/dark mode included -- and copy-paste ownership, where components land in your own project as real, editable source instead of a black-box dependency. 

npx zaytoon init
npx zaytoon add button
