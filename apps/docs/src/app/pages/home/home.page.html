Zaytoon

An Angular UI library built on two ideas: provider-based theming -- one call wires up a full design-token system with light/dark mode included -- and copy-paste ownership, where components land in your own project as real, editable source instead of a black-box dependency. 

npx zaytoon init
npx zaytoon add button

Components

  • Error Message — animated error text, standalone or used by the form components below.
  • Button — variants, sizes, loading state, icons.
  • Text Input — ngModel, reactive forms, Signal Forms.
  • Password — same form support, plus a show/hide toggle.
  • Select — listbox select with search, clear, and custom template slots.
  • Switch — toggle switch with sizes and optional on/off icons.
  • Checkbox — checkbox with sizes and an indeterminate state.
  • Radio Group — radio group with the same options shape as Select.
  • Textarea — multi-line text input with auto-resize and a character counter.
  • Input Number — numeric input with stepper buttons, min/max, and prefix/suffix.
  • OTP — one-time-password input with auto-advance and paste support.
  • Multiselect — multi-select listbox with chips, search, and select all/clear all.
  • Popover — reference-controlled popover, positioned against whatever triggered it.
  • Tooltip — [zTooltip] directive, works on any element.
  • Divider — horizontal or vertical rule, with an optional centered label.
  • Skeleton — shimmering loading placeholder, rect/circle/text shapes.
  • Avatar — image avatar with initials/icon fallback and a status dot.
  • Tag — small label/chip with color variants and a removable state.
  • Breadcrumb — a trail of ancestor pages, using RouterLink.
  • Pagination — page-number buttons that collapse to an ellipsis for large page counts.
  • Rating — star rating with ngModel/reactive/Signal Forms support.
  • Badge — notification count/dot indicator, overlay or standalone.
  • Accordion — data-driven collapsible panels with a pure-CSS expand animation.
  • Tabs — data-driven tab strip with a measured sliding indicator and keyboard navigation.
  • Stepper — step progress indicator with linear mode and horizontal/vertical orientation.
