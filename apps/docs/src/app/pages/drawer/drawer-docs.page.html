Drawer

A panel that slides in from a viewport edge, controlled by reference like Dialog: call drawer.show() / drawer.hide() / drawer.toggle() from anywhere. Same behavior under the hood as Dialog -- portals to document.body, traps focus, locks background scroll, restores focus on close -- the difference is purely presentational.

Installation

npx semiui add drawer

Basic usage (right side)

Open drawer

Drawer content goes here -- forms, lists, anything.

Cancel Save 
<s-button (click)="dr.show()">Open drawer</s-button>

<s-drawer #dr title="Edit profile">
  <p>Drawer content</p>
  <ng-template #footer>
    <s-button [outlined]="true" (click)="dr.hide()">Cancel</s-button>
    <s-button (click)="dr.hide()">Save</s-button>
  </ng-template>
</s-drawer>

Headless template

#headless replaces the entire header/body/footer chrome with raw projected content -- the drawer still portals, traps focus, and animates, but none of the default layout, padding, title, or close button is rendered.

    <div class="my-custom-drawer">...</div>
  </ng-template>
</s-drawer>

Blur backdrop & hidden backdrop

blurBackdrop adds a backdrop-filter: blur() behind the drawer in addition to dimming it. showBackdrop (default true) can be set to false to remove the dimming/blur entirely -- the drawer still portals, traps focus, and locks scroll, it just doesn't visually cover the page behind it.

Blurred backdrop No backdrop

The page behind this drawer is dimmed and blurred.

No dimming layer behind this drawer -- everything else stays interactive-looking, though the drawer still traps focus.

 
<s-drawer #dr [blurBackdrop]="true">...</s-drawer>
<s-drawer #dr [showBackdrop]="false">...</s-drawer>

Options

  • title -- plain-text header, ignored if a #header or #headless template is provided.
  • side -- "left" / "right" (default) / "top" / "bottom".
  • size -- controls width (left/right) or height (top/bottom): "sm" / "md" (default) / "lg" / "full".
  • closable -- default true; shows the "x" close button.
  • closeOnOutsideClick / closeOnEscape -- default true.
  • blurBackdrop -- default false; blurs whatever is behind the backdrop, in addition to dimming it.
  • showBackdrop -- default true; set to false to remove the dimming/blur layer entirely.

Methods

  • show() / hide() / toggle() -- same as Dialog.
