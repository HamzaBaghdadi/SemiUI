Drawer

A panel that slides in from a viewport edge, controlled by reference like Dialog: call drawer.show() / drawer.hide() / drawer.toggle() from anywhere. Same behavior under the hood as Dialog -- portals to document.body, traps focus, locks background scroll, restores focus on close -- the difference is purely presentational.

Installation

npx zaytoon add drawer

Basic usage (right side)

Open drawer

Drawer content goes here -- forms, lists, anything.

Cancel Save 
<z-button (click)="dr.show()">Open drawer</z-button>

<z-drawer #dr title="Edit profile">
  <p>Drawer content</p>
  <ng-template #footer>
    <z-button variant="outline" (click)="dr.hide()">Cancel</z-button>
    <z-button (click)="dr.hide()">Save</z-button>
  </ng-template>
</z-drawer>

Sizes

Small Large

A narrower panel.

More room for content.

 
<z-drawer #dr size="sm">...</z-drawer>  <!-- "sm" | "md" (default) | "lg" | "full" -->

Options

  • title -- plain-text header, ignored if a #header template is provided.
  • side -- "left" / "right" (default) / "top" / "bottom".
  • size -- controls width (left/right) or height (top/bottom): "sm" / "md" (default) / "lg" / "full".
  • closable -- default true; shows the "x" close button.
  • closeOnOutsideClick / closeOnEscape -- default true.

Methods

  • show() / hide() / toggle() -- same as Dialog.
