Radio Group

A radio group: one bound value across a set of native <input type="radio"> elements sharing a generated name, so arrow-key navigation between options is free native browser behavior. Options follow the same shape as Select -- plain values, or objects via optionLabel / optionValue.

Installation

npx semiui add radio-group

Primitive options

Model value: {{ fruit }}

<s-radio-group [options]="['Apple', 'Banana', 'Cherry']" [(ngModel)]="fruit" />

Option objects, with a disabled option

optionDisabled reads a per-option disabled flag, when options are objects.

Model value: {{ plan }}

<s-radio-group [options]="plans" optionLabel="name" optionValue="id" optionDisabled="disabled" [(ngModel)]="selectedPlan" />

Reactive forms + validation

protected reactiveForm = new FormGroup({
  plan: new FormControl<string | undefined>(undefined, Validators.required),
});

<div [formGroup]="reactiveForm">
  <s-radio-group [options]="plans" optionLabel="name" optionValue="id" formControlName="plan" errorMessage="Please choose a plan." />
</div>

Signal Forms

Model value: {{ profileModel().plan }}

protected profileModel = signal({ plan: 'free' });
protected profileForm = form(this.profileModel);

<s-radio-group [options]="plans" optionLabel="name" optionValue="id" [formField]="profileForm.plan" />

Horizontal direction

<s-radio-group direction="horizontal" />  <!-- default is "vertical" -->

Sizes

<s-radio-group size="sm" />  <!-- also "md" (default) and "lg" -->
