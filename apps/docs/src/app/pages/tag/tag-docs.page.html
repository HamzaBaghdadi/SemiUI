Tag

A small label/chip with color variants, an optional leading icon, and a removable state.

Installation

npx semiui add tag

Variants

Default Primary Secondary Destructive Outline 
<s-tag variant="primary">Primary</s-tag>

Severity

The same shared semantic color vocabulary as Button and Badge.

Success Info Warn Help Danger Contrast 
<s-tag variant="success">Success</s-tag>

With an icon

Verified 
<s-tag [icon]="{ type: 'ng-icon', name: 'lucideCheck' }">Verified</s-tag>
