Checkbox

A checkbox supporting ngModel, reactive forms, and Signal Forms. Built on a real native <input type="checkbox"> (visually hidden, styled via a sibling box), so keyboard interaction and assistive tech semantics come for free.

Installation

npx zaytoon add checkbox

ngModel

Model value: {{ subscribed }}

<z-checkbox [(ngModel)]="subscribed" label="Subscribe to updates" />

Reactive forms + validation

protected reactiveForm = new FormGroup({
  terms: new FormControl(false, { nonNullable: true, validators: Validators.requiredTrue }),
});

<div [formGroup]="reactiveForm">
  <z-checkbox formControlName="terms" label="I agree to the terms" errorMessage="You must agree to continue." />
</div>

Signal Forms

Model value: {{ profileModel().marketing }}

protected profileModel = signal({ marketing: false });
protected profileForm = form(this.profileModel);

<z-checkbox [formField]="profileForm.marketing" label="Marketing emails" />

Sizes

<z-checkbox size="sm" />  <!-- also "md" (default) and "lg" -->

Indeterminate

Purely presentational -- shows a dash instead of a checkmark without changing the bound value.

<z-checkbox [indeterminate]="true" label="Select all" />
