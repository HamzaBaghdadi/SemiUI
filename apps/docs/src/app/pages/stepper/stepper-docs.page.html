Stepper

A step progress indicator: pass items (each needs at least a label, optionally a description). Steps show as completed (checkmark), active, or upcoming, based on how they compare to activeIndex. Clicking a step's circle jumps to it; set linear to block clicking more than one step ahead, so users must progress via next() / previous(). An optional #content template slot renders the active step's panel below the indicator -- omit it to use Stepper as a pure visual indicator next to content you manage elsewhere.

Installation

npx zaytoon add stepper

Basic usage (free navigation)

Content for {{ item.label }} -- {{ item.description }}.

 
protected steps = [
  { label: 'Cart', description: 'Review items' },
  { label: 'Shipping', description: 'Delivery address' },
  { label: 'Payment', description: 'Card details' },
  { label: 'Confirm', description: 'Place order' },
};

<z-stepper [items]="steps">
  <ng-template #content let-item>
    <p>Content for {{ '{{ item.label }}' }}</p>
  </ng-template>
</z-stepper>

Linear mode with next()/previous()

Steps ahead of the immediate next one are unclickable -- use the buttons (or call next() / previous() on the component instance) to progress.

Content for {{ item.label }} -- {{ item.description }}.

 
<z-stepper #stepper [items]="steps" [linear]="true">...</z-stepper>
<button (click)="stepper.previous()">Previous</button>
<button (click)="stepper.next()">Next</button>

Vertical orientation

Content for {{ item.label }} -- {{ item.description }}.

 
<z-stepper [items]="steps" orientation="vertical">...</z-stepper>

Pure indicator (no #content)

Omit the #content template to use Stepper as just the visual progress row.

Options

  • items -- array of { label: string; description?: string; disabled?: boolean }.
  • activeIndex -- two-way bindable, default 0.
  • orientation -- "horizontal" (default) or "vertical".
  • linear -- default false; blocks clicking more than one step ahead.
