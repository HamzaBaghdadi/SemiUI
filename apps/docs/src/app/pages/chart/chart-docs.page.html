Chart

An SVG chart supporting line, bar, area, pie, and donut via a single type input -- no canvas, no external charting library, so it themes like any other component. Hover a point/bar/slice for its exact value; for line/bar/area, click a legend entry to toggle that series' visibility.

Installation

npx semiui add chart

Line

protected labels = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'];
protected series = [{ name: 'Revenue', values: [4200, 5100, 4800, 6300, 7100, 6800] }];

<z-chart type="line" [labels]="labels" [series]="series" />

Multiple series (line)

protected series = [
  { name: '2025', values: [3200, 4100, 3800, 5300, 5900, 5600] },
  { name: '2026', values: [4200, 5100, 4800, 6300, 7100, 6800] },
};

<z-chart type="line" [labels]="labels" [series]="series" />

<z-chart type="bar" [labels]="labels" [series]="series" />

<z-chart type="area" [labels]="labels" [series]="series" />

Pie

protected labels = ['Chrome', 'Safari', 'Firefox', 'Edge', 'Other'];

Donut

<z-chart type="donut" [labels]="labels" [series]="series" />

No grid, no legend

<z-chart type="bar" [labels]="labels" [series]="series" [showGrid]="false" [showLegend]="false" />

Options

  • type -- "line" (default) / "bar" / "area" / "pie" / "donut".
  • labels -- x-axis categories (cartesian types) or slice labels (pie/donut).
  • series -- array of { name, values, color? }. Pie/donut use only series[0].
  • height -- pixels, default 320.
  • showLegend / showGrid -- default true.
  • valueFormatter -- (value: number) => string, formats axis labels and tooltip values.
  • colors -- palette array, cycles by index when a series/slice has no explicit color.
