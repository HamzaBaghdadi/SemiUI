Password

Wraps the same behavior as Text Input, plus a reveal toggle controlled by showMask.

Installation

npx semiui add password

ngModel

<z-password [(ngModel)]="password" />

Reactive forms + validation

protected reactiveForm = new FormGroup({
  password: new FormControl('', [Validators.required, Validators.minLength(8)]),
});

<div [formGroup]="reactiveForm">
  <z-password formControlName="password" errorMessage="Password must be at least 8 characters" />
</div>

showMask

showMask controls whether the show/hide toggle button renders at all.

<z-password [showMask]="false" />  <!-- no reveal button, always masked -->
