File Upload

A drag-and-drop / click-to-browse file picker. Selecting or dropping files validates them against accept/maxFileSize/maxFiles and adds the accepted ones to the bound value, showing any rejected files with their reason. Only handles selection, validation, and preview -- actually uploading the files is up to you, since that's inherently app-specific (which endpoint, what payload shape, progress reporting, retry behavior).

Installation

npx zaytoon add file-upload

Basic usage

{{ files.length }} file(s) selected

<z-file-upload [(ngModel)]="files" [multiple]="true" />

Image previews

Image files get a thumbnail preview automatically; other file types show a generic file icon.

<z-file-upload [(ngModel)]="images" accept="image/*" [multiple]="true" />

Validation

maxFileSize (bytes) and maxFiles reject files past the limit, shown with their reason below the dropzone.

<z-file-upload [(ngModel)]="documents" [maxFiles]="2" [maxFileSize]="1048576" accept=".pdf,.doc,.docx" />
<!-- maxFileSize is in bytes -- 1048576 = 1 MB -->

Single file

<z-file-upload [(ngModel)]="file" [multiple]="false" />

Disabled

Options

  • accept -- comma-separated MIME types, wildcards (image/*), or extensions (.pdf). Empty accepts everything.
  • multiple -- default true.
  • maxFileSize -- bytes, per file.
  • maxFiles -- total file count.
