Error Message

Displays a message with an enter/leave animation, using Angular's native animate.enter / animate.leave template syntax -- no animations package required. Text Input and Password use it internally for their errorMessage input; it's also a standalone component for any error text of your own.

Installation

npx semiui add error-message

Usage

<z-error-message [message]="errorMessage()" />

Renders nothing when message is empty -- no empty, invisible element left in the DOM. The text always displays in full: no truncation, no fixed height, it wraps normally.
