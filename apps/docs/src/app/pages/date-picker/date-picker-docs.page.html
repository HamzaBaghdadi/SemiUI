Date Picker

A calendar date picker: a read-only text field that opens a viewport-aware calendar panel on click, or set inline to render the calendar directly with no input and no popover. Supports ngModel, reactive forms, and Signal Forms. Keyboard: arrow keys move by day, Home/End jump to the start/end of the week, PageUp/PageDown change month, Enter/Space selects.

Installation

npx zaytoon add date-picker

Basic usage (ngModel)

Model value: {{ birthday | date }}

<z-date-picker [(ngModel)]="birthday" placeholder="Pick your birthday" />

Inline

No input, no popover -- the calendar renders directly, e.g. for a dedicated "pick a date" page or a sidebar widget.

<z-date-picker [(ngModel)]="date" [inline]="true" />

min/max and disabled dates

This one only allows the last 7 days up to today, and disables weekends within that range.

protected isWeekend = (date: Date) => date.getDay() === 0 || date.getDay() === 6;

<z-date-picker [(ngModel)]="date" [minDate]="minDate" [maxDate]="maxDate" [isDateDisabled]="isWeekend" />

Reactive forms

protected reactiveForm = new FormGroup({
  appointment: new FormControl<Date | null>(null, Validators.required),
});

<div [formGroup]="reactiveForm">
  <z-date-picker formControlName="appointment" errorMessage="Please pick a date." />
</div>

Signal Forms

Model value: {{ profileModel().birthday | date }}

protected profileModel = signal({ birthday: new Date(1995, 5, 15) });
protected profileForm = form(this.profileModel);

<z-date-picker [formField]="profileForm.birthday" />

Custom date format

protected fmt = (date: Date) => date.toISOString().slice(0, 10); // "2026-08-02"

<z-date-picker [(ngModel)]="date" [dateFormat]="fmt" />

Month/year navigation, Today button, header/footer templates

Click the month/year label to drill down into a 12-month grid, then a 12-year grid, for jumping further than one click at a time -- selecting drills back down. showTodayButton adds a footer button that jumps to and selects today. #header/#footer templates render inside the panel, above/below the calendar.

Pick a date 
<z-date-picker [showTodayButton]="true">
  <ng-template #header><strong>Pick a date</strong></ng-template>
</z-date-picker>

Time picker (12h/24h)

showTime adds hour/minute controls below the calendar -- the picked day and time combine into one Date. timeFormat is "24h" (default) or "12h" (adds an AM/PM toggle). The panel stays open after picking a day so you can also adjust the time before closing it. 

<z-date-picker [showTime]="true" />
<z-date-picker [showTime]="true" timeFormat="12h" />

Time-only and manual text entry

timeOnly hides the calendar entirely, showing just the time controls (implies showTime). manualInput lets you type directly into the field instead of only opening the panel by click -- committed via parseDate (defaults to new Date(text)) on blur or Enter; an unparseable value reverts to the last valid one. 

<z-date-picker [timeOnly]="true" />
<z-date-picker [manualInput]="true" />

Multiple dates and range selection

selectionMode="multiple" binds through [(multipleValue)] (a Date[]) instead of value -- clicking a day toggles it in/out, and the panel stays open across picks. selectionMode="range" binds through [(rangeValue)] (a { start: Date; end: Date | null }) -- the first click starts a range, the second completes it (order doesn't matter, they're sorted automatically) and closes the panel. These two modes are plain two-way bindings, not routed through ngModel/reactive forms/Signal Forms the way the default single mode is.

Multiple: {{ multipleDates.length }} date(s) selected

Range: {{ dateRange ? (dateRange.start | date) + ' - ' + (dateRange.end ? (dateRange.end | date) : '...') : 'none' }}

<z-date-picker selectionMode="multiple" [(multipleValue)]="multipleDates" />
<z-date-picker selectionMode="range" [(rangeValue)]="dateRange" />

Options

  • inline -- default false.
  • clearable -- default true.
  • minDate / maxDate -- Date, inclusive.
  • isDateDisabled -- (date: Date) => boolean, checked alongside min/max.
  • dateFormat -- (date: Date) => string, formats the trigger's displayed text.
  • showTodayButton -- default false; adds a footer "Today" button that jumps to and selects the current date.
  • showTime -- default false; adds hour/minute controls. timeFormat -- "24h" (default) or "12h".
  • timeOnly -- default false; hides the calendar, showing just the time controls (implies showTime).
  • manualInput -- default false; lets the field be typed into directly. parseDate -- (text: string) => Date | null, defaults to new Date(text).
  • selectionMode -- "single" (default, via value) / "multiple" (via [(multipleValue)]) / "range" (via [(rangeValue)]).
