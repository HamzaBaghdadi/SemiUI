Tabs

A data-driven tab strip: pass items (each needs at least a label) and render the active panel's body through the required #content template slot -- same convention as Accordion's #content and Select's #option. The sliding indicator is positioned by measuring the active tab's real rendered box, so it tracks variable-width labels correctly. Keyboard navigation follows the ARIA "tabs" pattern: arrow keys move focus and selection together, Home/End jump to the first/last enabled tab, disabled tabs are skipped.

Installation

npx semiui add tabs

Basic usage

Content for {{ item.label }}.

 
protected items = [
  { label: 'Profile' },
  { label: 'Billing' },
  { label: 'Notifications', disabled: true },
};

<z-tabs [items]="items">
  <ng-template #content let-item>
    <p>Content for {{ '{{ item.label }}' }}</p>
  </ng-template>
</z-tabs>

The "Notifications" tab above has disabled: true -- it's skipped by both click and arrow-key navigation.

Controlled activeIndex

activeIndex is a two-way bindable model() -- drive it programmatically, or bind it with [(activeIndex)].

Content for {{ item.label }}.

 
protected activeIndex = signal(0);

<z-tabs [items]="items" [(activeIndex)]="activeIndex" />

Vertical orientation

Content for {{ item.label }}.

 
<z-tabs [items]="items" orientation="vertical">...</z-tabs>

Custom label template

{{ i + 1 }}. {{ item.label }}

Content for {{ item.label }}.

 
<z-tabs [items]="items">
  <ng-template #label let-item let-i="index">
    <strong>{{ '{{ i + 1 }}' }}.</strong> {{ '{{ item.label }}' }}
  </ng-template>
  <ng-template #content let-item>...</ng-template>
</z-tabs>

Options

  • items -- array of { label: string; disabled?: boolean } (extend the interface for extra fields your templates need).
  • activeIndex -- two-way bindable, default 0.
  • orientation -- "horizontal" (default) or "vertical".
