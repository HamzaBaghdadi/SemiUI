Installation

SemiUI splits into two kinds of package: an engine you install normally from npm, and components you copy into your own project with the CLI instead of installing. This page covers the engine. See Quick Start for adding your first component.

Requires Angular 22 or later (standalone APIs, signal inputs, and Signal Forms).

Recommended: the CLI

npx @semiui/cli init

This installs everything below for you and prints the exact lines to add to app.config.ts. See CLI Reference for the full command list.

Manual installation

If you'd rather wire things up yourself, install the engine packages directly:

npm install @semiui/tokens @semiui/theme @semiui/primitives @semiui/presets-aurora
Package What it's for
@semiui/tokens The design token contract (colors, spacing, component tokens) as plain TypeScript types and the flattenTokensToCssVars utility. No Angular dependency.
@semiui/theme provideSemiUI() and ColorModeService -- turns a preset's tokens into a live stylesheet and handles light/dark mode.
@semiui/primitives Unstyled behavior directives and helpers (ButtonDirective, InputDirective, SIconComponent, BaseFormFieldControl) that components are built on.
@semiui/presets-aurora The default preset: a complete light + dark color palette and component tokens.

Then wire up the theme provider in app.config.ts:

import { ApplicationConfig } from '@angular/core';
import { provideSemiUI } from '@semiui/theme';
import { Aurora, provideAuroraIcons } from '@semiui/presets-aurora';

export const appConfig: ApplicationConfig = {
  providers: [
    // ...your existing providers
    provideSemiUI({ preset: Aurora }),
    provideAuroraIcons(),
  ],
};

provideSemiUI injects the preset's tokens as CSS custom properties and installs ColorModeService so light/dark mode works immediately -- see Theming and Color Mode for what each of those calls actually does.

Adding a component

npx semiui add button

Components aren't an npm dependency -- add copies the component's real source (.ts, .html, .css) into your project and installs whatever it needs from the table above. From that point it's your code to edit.
