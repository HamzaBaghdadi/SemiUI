Accordion

A data-driven accordion: pass items (each needs at least a header) and render each panel's body through the required #content template slot. Single-open by default -- opening one panel closes the others -- set multiple to allow several open at once. The expand/collapse animation is pure CSS, no JS height measurement involved.

Installation

npx zaytoon add accordion

Basic usage

{{ $any(item).answer }}

 
protected faqs = [
  { header: 'What is Zaytoon?', answer: '...' },
  { header: 'Is it free?', answer: '...' },
};

<z-accordion [items]="faqs">
  <ng-template #content let-item>
    <p>{{ '{{ item.answer }}' }}</p>
  </ng-template>
</z-accordion>

Multiple open at once

Content for {{ $any(item).header }} (index {{ i }}).

 
<z-accordion [items]="sections" [multiple]="true" [defaultOpenIndices]="[0, 1]">
  <ng-template #content let-item>...</ng-template>
</z-accordion>

The third section above has disabled: true on its item -- its header is unclickable and dimmed.

Custom header template

Q{{ i + 1 }}. {{ $any(item).header }}

{{ $any(item).answer }}

 
<z-accordion [items]="faqs">
  <ng-template #header let-item let-i="index">
    <strong>Q{{ '{{ i + 1 }}' }}.</strong> {{ '{{ item.header }}' }}
  </ng-template>
  <ng-template #content let-item><p>{{ '{{ item.answer }}' }}</p></ng-template>
</z-accordion>

Options

  • items -- array of { header: string; disabled?: boolean } (extend the interface for extra fields your templates need).
  • multiple -- default false (only one panel open at a time).
  • defaultOpenIndices -- indices expanded on initial render, default [].
