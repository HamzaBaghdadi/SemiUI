Badge

A small notification indicator -- not only a number: a plain dot, arbitrary text, an icon, or a number ("N+" once past max). By default it overlays whatever is projected into it (an icon, an avatar); set standalone to render inline instead, e.g. next to a text label.

Installation

npx zaytoon add badge

Text and icon content

Not limited to a number -- label shows arbitrary text, icon renders a z-icon instead. icon takes priority over label, which takes priority over count.

<z-badge label="NEW" variant="info" [standalone]="true" />
<z-badge [icon]="starIcon" variant="warn" [standalone]="true" ariaLabel="Featured" />

Overlaying an icon

<z-badge [count]="unreadCount">
  <button aria-label="Notifications">🔔</button>
</z-badge>

Max count ("N+")

<z-badge [count]="150" [max]="99">...</z-badge>  <!-- shows "99+" -->

Dot

<z-badge [dot]="true" variant="destructive">...</z-badge>

Position and variants

@for (position of positions; track position) { } 
<z-badge [count]="1" position="bottom-left" variant="secondary">...</z-badge>

Severity

The same shared semantic color vocabulary as Button and Tag.
