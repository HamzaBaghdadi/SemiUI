Input Number

A numeric input with increment/decrement buttons, min/max/step clamping, and prefix/suffix text. The bound value is number | null -- null for an empty field, never NaN.

Installation

npx zaytoon add input-number

ngModel

Model value: {{ quantity }}

<z-input-number [(ngModel)]="quantity" [min]="0" [max]="10" />

Reactive forms + validation

min/max clamp the value itself (see below), which would make a redundant Validators.min/max unreachable -- so this demo pairs errorMessage with Validators.required instead. Clear the field and blur to see it. 

protected reactiveForm = new FormGroup({
  age: new FormControl<number | null>(null, Validators.required),
});

<div [formGroup]="reactiveForm">
  <z-input-number formControlName="age" errorMessage="Age is required." />
</div>

Signal Forms

Model value: {{ profileModel().price }}

protected profileModel = signal({ price: 19.99 });
protected profileForm = form(this.profileModel);

<z-input-number [formField]="profileForm.price" [step]="0.01" prefix="$" />

Prefix / suffix

Rendered as separate elements flanking the field, not embedded in the value -- keeps parsing simple.

<z-input-number prefix="$" suffix=".00" [showButtons]="false" />

Keyboard

↑ / ↓ step the value while the field is focused, same as clicking the buttons.
