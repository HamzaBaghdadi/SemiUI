Breadcrumb

A trail of ancestor pages, using Angular's RouterLink for navigable items. Any item with a link renders as a real, clickable anchor -- whether it's styled as the current page comes from routerLinkActive (exact match against the actual router URL), not from being last in the array. An item without a link renders as plain, non-navigable text instead.

In the demo below, "Components" links to this exact page (/components/breadcrumb) -- notice it's styled as the current page even though it's the second item, not the last, because the router confirms it's genuinely the active route.

Installation

npx semiui add breadcrumb

Basic usage

protected items = [
  { label: 'Home', link: '/' },
  { label: 'Components', link: '/components/breadcrumb' },  <!-- styled current when the router URL matches, not because it's "last" -->
  { label: 'Breadcrumb' },  <!-- no link -- always plain, non-navigable text -->
];

<s-breadcrumb [items]="items" />
