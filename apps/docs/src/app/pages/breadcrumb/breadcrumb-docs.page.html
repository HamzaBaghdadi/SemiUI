Breadcrumb

A trail of ancestor pages, using Angular's RouterLink for navigable items. The last item (or any item without a link) renders as the current, non-linked page.

Installation

npx zaytoon add breadcrumb

Basic usage

protected items = [
  { label: 'Home', link: '/' },
  { label: 'Components', link: '/components' },
  { label: 'Breadcrumb' },  <!-- no link -- current page -->
];

<z-breadcrumb [items]="items" />
