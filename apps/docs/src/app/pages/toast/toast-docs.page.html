Toast

A ToastService injectable from anywhere in your app, plus a <z-toast-container> you mount once (typically in your app root component's template) to render whatever's queued. Call toastService.success('Saved!') from any component, service, or interceptor -- no reference to the container needed.

Installation

npx zaytoon add toast
// app.ts
@Component({
  imports: [ToastContainerComponent, RouterOutlet],
  template: `<router-outlet /><z-toast-container />`,
})
export class App {}

The container below is mounted directly on this page (rather than the app root) just for this demo -- ToastService is a root-provided singleton either way, so this works identically to mounting it once at the top of your app.

Variants

protected toastService = inject(ToastService);

toastService.show({ title: 'Notification', description: '...' });
toastService.success('Your changes have been saved.', 'Success');
toastService.error('Something went wrong.', 'Error');
toastService.warning('Session expires in 5 minutes.', 'Warning');
toastService.info('A new version is available.', 'Info');

Sticky (no auto-dismiss) and clear all

toastService.show({ title: 'Sticky', description: '...', duration: 0 });  // 0 = no auto-dismiss
toastService.clear();

Hover a toast to pause its auto-dismiss timer -- it restarts (from the full duration) on mouse leave.

Icon and custom template

showIcon: false suppresses the variant icon for a single toast. For full control, template replaces the icon/title/description/close-button chrome entirely with your own <ng-template> -- context is { $implicit: the toast entry, dismiss: () => void }.

🎉 Fully custom content 
toastService.show({ title: 'No icon', showIcon: false });

<ng-template #customToast let-toast let-dismiss="dismiss">
  <div>🎉 Fully custom content <button (click)="dismiss()">Close</button></div>
</ng-template>
// toastService.show({ template: customToastTemplate });

Stacked (peek deck)

stacked collapses queued toasts into a peeking deck instead of a growing list -- hovering the group expands them into a normal spaced-out list, moving the mouse away collapses them back. 

<z-toast-container [stacked]="true" />

Position

Current position: {{ position() }} -- trigger a toast above to see it.

<z-toast-container position="bottom-right" />

Options

  • ToastOptions -- title?, description?, variant? ("default" / "success" / "error" / "warning" / "info"), duration? (ms, default 5000, 0 = sticky), showIcon? (default true), template? (TemplateRef for fully custom content).
  • ToastContainerComponent.position -- one of the six corners/centers above, default "top-right".
  • ToastContainerComponent.stacked -- default false; collapses queued toasts into a peeking deck that expands on hover.
  • Width, blur, and per-severity background/border/icon colors are all theme tokens (comp.toast.width, comp.toast.maxWidth, comp.toast.blur, comp.toast.variants.*) -- see Theming.

Methods

  • show(options) -- returns the toast's id.
  • success(description, title?) / error(...) / warning(...) / info(...)
  • dismiss(id) / clear()
