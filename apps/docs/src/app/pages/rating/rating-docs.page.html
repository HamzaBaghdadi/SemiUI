Rating

A star rating: whole stars only, maxStars of them (default 5). Clicking the currently-selected star clears it back to no rating.

Installation

npx zaytoon add rating

ngModel

Model value: {{ stars }}

<z-rating [(ngModel)]="stars" />

Reactive forms + validation

Validators.min treats a null value as "empty, skip validation" (per Angular's own isEmptyInputValue) rather than "too low", so it'd never actually fire here -- same reason Input Number's validation demo uses Validators.required instead. 

protected reactiveForm = new FormGroup({
  stars: new FormControl<number | null>(null, Validators.required),
});

<div [formGroup]="reactiveForm">
  <z-rating formControlName="stars" />
</div>

Signal Forms

Model value: {{ profileModel().stars }}

protected profileModel = signal({ stars: 4 });
protected profileForm = form(this.profileModel);

<z-rating [formField]="profileForm.stars" />

Max stars and sizes

<z-rating [maxStars]="10" size="sm" />  <!-- size also "md" (default), "lg" -->

Readonly (e.g. displaying an average)

<z-rating [ngModel]="averageRating" [readOnly]="true" />
