Table

A data-driven table: pass columns and data. Sorting, a global filter box, row selection, and pagination (reusing Pagination) are all opt-in via inputs -- a plain read-only table stays plain. An optional #cell template slot customizes rendering per cell; context is { $implicit: row, column, value, index }, so the template typically @switches on column.field.

Installation

npx zaytoon add table

Basic usage with sorting

protected columns: TableColumn<Person>[] = [
  { field: 'name', header: 'Name', sortable: true },
  { field: 'email', header: 'Email', sortable: true },
  { field: 'role', header: 'Role', sortable: true },
  { field: 'age', header: 'Age', sortable: true, align: 'right', width: '5rem' },
};

<z-table [columns]="columns" [data]="people" />

Custom cell template

Renders a colored Tag for the status column instead of plain text.

@if (column.field === 'status') { {{ value }} } @else { {{ value }} } 
<z-table [columns]="columns" [data]="people">
  <ng-template #cell let-row let-column="column" let-value="value">
    @if (column.field === 'status') {
      <z-tag [variant]="statusVariant(value)">{{ '{{ value }}' }}</z-tag>
    } @else {
      {{ '{{ value }}' }}
    }
  </ng-template>
</z-table>

Filterable, selectable, paginated

47 rows, filtered client-side across every column, multi-select with a header "select all visible" checkbox, 10 rows per page.

{{ selection.length }} row(s) selected

  [data]="people"

  [paginated]="true"

/>

Single selection

<z-table [columns]="columns" [data]="people" selectionMode="single" />

Sorting is opt-in per column

There's no table-wide "enable sorting" switch -- each column decides for itself via sortable. Omit it everywhere (like this one does) and the table is just a plain, unsortable grid; no sort icons, no clickable headers. 

protected columns: TableColumn<Person>[] = [
  { field: 'name', header: 'Name' },  // no sortable -- this column never sorts
};

Summary, rows-per-page, and header/footer templates

showSummary adds a "Showing X to Y of Z entries" label -- customize the wording via summaryTemplate's {first}/{last}/{total} placeholders. rowsPerPageOptions adds a page-size dropdown (via Select) that writes back to [(pageSize)]. #header/#footer templates render in the toolbar/footer alongside all of that. With nothing else in the footer, pagination centers itself instead of sitting flush right.

{{ manyPeople.length }} people 
<z-table
  [columns]="columns"
  [data]="people"
  [paginated]="true"
  [(pageSize)]="pageSize"
  [rowsPerPageOptions]="[5, 10, 25]"
  [showSummary]="true"
  summaryTemplate="{first}-{last} of {total}"
>
  <ng-template #header>...</ng-template>
  <ng-template #footer>...</ng-template>
</z-table>

Loading and empty states

Fetching people, hold on…
 
<z-table [loading]="isLoading()">
  <ng-template #loading>Fetching people, hold on&hellip;</ng-template>
</z-table>

Options

  • columns -- array of { field, header, sortable?, width?, align?, sortFn? }.
  • data -- any array of row objects.
  • rowKey -- (row) => unknown, identity function for selection tracking; defaults to the row object itself.
  • selectionMode -- "none" (default) / "single" / "multiple".
  • selection -- two-way bindable array of selected rows.
  • filterable -- default false; global search across every column's field value.
  • paginated -- default false; pageSize default 10, two-way bindable.
  • rowsPerPageOptions -- default [] (hidden); a page-size dropdown when non-empty, e.g. [5, 10, 25].
  • showSummary -- default false; a "Showing X to Y of Z entries" label. summaryTemplate customizes the wording via {first}/{last}/{total} placeholders.
  • loading / striped / stickyHeader / emptyMessage.

Templates

  • #cell -- per-cell rendering. Context: { $implicit: row, column, value, index }.
  • #header -- rendered in the toolbar, alongside the filter box.
  • #footer -- rendered in the footer, alongside the summary/rows-per-page dropdown/pagination.
  • #loading -- replaces the default spinner + "Loading..." row while loading is true.

Outputs

  • rowClick -- emits the clicked row, regardless of selectionMode.
