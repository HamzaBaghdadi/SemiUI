Multiselect

A multi-select listbox: same options / optionLabel / optionValue shape as Select, plus checkbox-style rows and chips in the trigger. Search/filter and clear are on by default, same as Select, and the panel is viewport-aware and animated the same way too. When showSelectAll is on (the default), a master checkbox in the lead of the filter row selects or clears every currently-filtered option -- checked when all are selected, a dash when some are.

Installation

npx semiui add multiselect

Primitive options

Model value: {{ selectedFruits | json }}

<z-multiselect [options]="['Apple', 'Banana', 'Cherry']" [(ngModel)]="selectedFruits" placeholder="Pick fruits" />

Option objects

Model value: {{ selectedSkillCodes | json }}

<z-multiselect [options]="skills" optionLabel="name" optionValue="code" [(ngModel)]="selectedSkillCodes" />

Reactive forms + validation

protected reactiveForm = new FormGroup({
  skills: new FormControl<string[]>([], { nonNullable: true, validators: Validators.required }),
});

<div [formGroup]="reactiveForm">
  <z-multiselect [options]="skills" optionLabel="name" optionValue="code" formControlName="skills" errorMessage="Pick at least one skill." />
</div>

Signal Forms

Model value: {{ profileModel().skills | json }}

protected profileModel = signal({ skills: ['ts', 'ng'] });
protected profileForm = form(this.profileModel);

<z-multiselect [options]="skills" optionLabel="name" optionValue="code" [formField]="profileForm.skills" />

Custom templates

Same five named <ng-template> slots as Select: #selected (the closed trigger's content -- context is the full array of selected options, not a single one), #option (each row in the list), #icon (replaces the default chevron), and #header / #footer (rendered above/below the list).

Same caveat as Select: Angular's strict template checker can't infer a concrete type for let-option on a content-projected <ng-template>. Wrap property access in $any(option) inside these templates -- it's a compile-time-only cast.

@for (option of options; track $index) { {{ $any(option).code }} } @empty { Pick skills… } {{ selected ? '✓' : '' }} {{ $any(option).name }} ({{ $any(option).code }}) Available Skills 
<z-multiselect [options]="skills" optionLabel="name" optionValue="code" [(ngModel)]="selectedSkillCodes">
  <ng-template #selected let-options>
    <!-- options is the full array of selected values -->
  </ng-template>
  <ng-template #option let-option let-selected="selected">
    {{ "{{ selected ? '✓' : '' }}" }} {{ '{{ option.name }}' }}
  </ng-template>
  <ng-template #header><strong>Available Skills</strong></ng-template>
</z-multiselect>

Removable chips

Chips render via Tag with removable on by default -- clicking the "x" on a chip removes just that selection without opening the panel. Set removableChips="false" for read-only chips. 

<z-multiselect [options]="fruits" [removableChips]="false" />

closeOnSelect and maxChipsDisplay

By default the panel stays open across selections and the trigger shows individual chips until maxChipsDisplay is exceeded (then it switches to "N selected"). Set closeOnSelect for single-pick-then-close behavior instead. 

<z-multiselect [closeOnSelect]="true" [maxChipsDisplay]="2" />

Loading

Same as Select: a spinner replaces the chevron, interaction is blocked, and it dims via opacity rather than the disabled palette.

<z-multiselect [loading]="true" />

Disabled

Append to body

Same as Select: set appendTo="body" to move the panel to a direct child of document.body, escaping an ancestor's clipping or stacking context while staying pixel-positioned against the trigger. 

<z-multiselect [options]="fruits" appendTo="body" />
