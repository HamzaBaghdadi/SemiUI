Text Input

A text field that works the same whether you use ngModel, reactive forms, or Signal Forms.

Installation

npx zaytoon add text-input

ngModel

Model value: {{ name }}

<z-text-input [(ngModel)]="name" [disabled]="nameDisabled()" />

Reactive forms

protected reactiveForm = new FormGroup({
  email: new FormControl('', [Validators.required, Validators.email]),
});

<div [formGroup]="reactiveForm">
  <z-text-input formControlName="email" errorMessage="Enter a valid email address" />
</div>

Signal Forms

Bind with [formField] from @angular/forms/signals -- no ControlValueAccessor involved.

Model value: {{ profileModel().username }}

protected profileModel = signal({ username: '' });
protected profileForm = form(this.profileModel);

<z-text-input [formField]="profileForm.username" />
